# Placeholder syntax

He marks gaps inline while drafting. Each bracket is an instruction, not a blank to fill mechanically.

## Existing conventions

| Marker | What it asks for |
|---|---|
| `[infuse something on X]` | Inject researched content on X. **Check placement first.** He marks where he felt a gap, not always where the concept belongs. If X would be a non-sequitur there, say so and relocate it to where it explains something. |
| `[infuse something from <person>]` | Find what that person actually said, verify the position, and place the quote where it does the most work. Often not where the marker sits. |
| `[Infuse what you think in terms of research and metrics]` | Find primary-source data that supports or complicates the argument. Prefer evidence that includes its own caveat, because a benchmark's stated limitation is stronger than an outside critique. |
| `curate this -> <text>` | Tighten his dictated text and consider relocating it. Usually needs to become concrete: replace generic claims with specific instances. |
| `[talk from an <angle> perspective]` | Reframe the section through that lens rather than adding a new paragraph about it. |
| `[if there are overlapping sentences or repetition, point it out]` | Run the Phase 4 sweep and report merges explicitly. |
| `[lets create diagrams wherever necessary]` | Decide where a visual makes an argument prose can't, insert markers, write specs. |

## Conventions worth proposing to him

If he'd find them useful, suggest adding:

| Marker | Meaning |
|---|---|
| `[verify]` | He's unsure of a fact and wants it checked before publish |
| `[park]` | He already thinks this belongs in a different article |
| `[cut?]` | He suspects this is weak and wants a second opinion |
| `[specific?]` | He knows this paragraph is too abstract and wants prompting for a concrete instance |

## Handling rules

**Answer every marker explicitly in the change log**, including ones you decided not to fill. A marker you silently skipped reads as a marker you missed.

**Disagreeing with a marker is a valid response.** If he asks you to infuse a concept that would be technically wrong or off-topic where he put it, the right move is to say so, explain why, and offer the version that survives scrutiny. This has already happened once and was the most valuable single intervention in the workflow.

**Markers can be answered by relocation.** "I didn't fill this here, I moved the idea to section 6 where it explains the iteration argument" is a complete answer.
